# Ícones dos bancos

| Arquivo | Origem | Licença |
|---|---|---|
| `postgres.svg` | Logo oficial do PostgreSQL (wiki.postgresql.org, "PostgreSQL_logo.3colors.svg") | Licença PostgreSQL (uso livre) |
| `firebird.svg` | Desenho próprio do Skorpa Data (pássaro de fogo) | Mesmo do projeto |
| `mysql.svg`, `oracle.svg`, `sqlite.svg` | [Simple Icons](https://simpleicons.org) 13.21.0 | CC0 |

As marcas pertencem aos respectivos donos; os ícones só identificam o tipo de banco.
Arquivo com `currentColor` recebe a cor definida em `theme.DB_ICON_COLORS`; os demais
já têm cores próprias. Para um banco sem arquivo aqui é usado o ícone genérico `database`.
